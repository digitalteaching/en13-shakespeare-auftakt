# Shakespeare · Before we begin

Auftakt zur *Macbeth*-Reihe Englisch EN13, vor dem Einführungs-Deck. Gruppen sammeln auf einem iPad Vorwissen, Hoffnungen und Sorgen zu Shakespeare und zeigen einen QR-Code. Die Lehrkraft scannt die Codes und führt das Ergebnis unter /lehrer/ als Wand in Stufen vor. Ohne Server, ohne Namen: Nichts verlässt den Raum.

Beide Seiten sind passwortgeschützt (Inhalt verschlüsselt).

Link: https://digitalteaching.github.io/en13-shakespeare-auftakt/ · Wand (Lehrkraft): https://digitalteaching.github.io/en13-shakespeare-auftakt/lehrer/
